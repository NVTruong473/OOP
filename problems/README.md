# OOP Challenge Statements

The catalog in `docs/PROBLEM_SET.md` is the progression map. This directory contains expanded LeetCode-style statements for representative design-heavy challenges.

Each challenge specifies an API goal, invariants, edge cases, and **change pressure**: a follow-up requirement designed to expose brittle object models. The implementation lives under `src/main/java`, while executable acceptance criteria live under `src/test/java`.
